What it does for you

Stock by garment type and size

Readymade Ledger records garment type and size, so you can see exactly what sizes are left.

Billing by type and size

Readymade Sale sells garments by type and size, adds GST to the subtotal and reduces stock from the ledger as you bill.

Barcode labels and scanning

Print barcode labels for stock and scan or type a barcode when billing. It works with any USB barcode scanner.

Questions

Can it track stock by size?

Yes. Readymade Ledger holds garment type and size, and sales reduce the right size automatically.

Can it give my accountant the GST figures?

GST Summary shows the GST on your bills for any period, by application, HSN code and bill, and exports to Excel. It is a summary of your own bills, not a GST return filing.

Which languages does it support?

Every screen can be switched between English, Hindi and Telugu.
